# My .dotfiles configurations

## Warning: This configuration is based on Arch Linux and KDE Plasma!

## Setup instructions

1. Then once done clone the repo on your home folder

```
cd ~
git clone --recurse-submodules https://github.com/Killarexe/.dotfiles.git
cd .dotfiles
```

2. Install all of these

```
sudo pacman -S cmake make vim vi neovim rofi i3wm feh xxd htop fastfetch tmux oh-my-posh-bin vesktop libreoffice python pip furnace lmms godot audacity libresprite prismlauncher arduino-ide-bin corrscope xrandr arandr kdenlive logisim-evolution-bin gimp gparted
```

Done!
